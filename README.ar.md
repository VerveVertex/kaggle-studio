<p align="center">بدّل النماذج، وابدأ الجلسات وأوقفها، من هاتفك.</p>

اجمع نماذجك الخاصة للمحادثة وإنشاء الصور والفيديو في تطبيق واحد لنظام Android. امنح التطبيق الإذن للوصول إلى حسابك في Cloudflare، وأدخل رمز API الخاص بك في Kaggle للعثور على تثبيت موجود أو إعداد نشر شخصي.

## هاتفك هو لوحة التحكم

- **بدّل النموذج باختياره:** اختر نموذج محادثة أو صور أو فيديو سبق نشره من القائمة. يتولى Studio إنهاء الجلسة السابقة وتحميل النموذج المحدد.
- **ابدأ عند الحاجة إلى قدرات GPU:** شغّل جلسة Kaggle من قسم Compute، وتابع حالة تحميل النموذج داخل التطبيق.
- **أوقف الجلسة حتى وأنت بعيد عن الكمبيوتر:** أرسل طلب الإيقاف من الهاتف، وتحقق من تأكيد Kaggle لانتهاء الجلسة. لا تتطلب الإدارة اليومية كمبيوتر أو سطح مكتب بعيدًا أو سطر أوامر.

التبديل ليس فوريًا؛ ينتظر Studio انتهاء الجلسة السابقة ثم يحمّل النموذج المحدد. يعمل نموذج واحد فقط على GPU في كل مرة.

## الإمكانات

| المجال | الوظائف |
|---|---|
| المحادثة | نماذج GGUF، ومحادثات طويلة، وعرض المعادلات الرياضية؛ تقبل نماذج الرؤية المتوافقة الصور والأسئلة المتعلقة بها |
| الصور | إعدادات SDXL وZ-Image؛ إنشاء صور من النص أو من صورة مرجعية |
| الفيديو | إعدادات Wan؛ إنشاء فيديو من النص، ومن الصور عند استخدام نموذج متوافق |
| النشر الشخصي | Worker وقاعدة D1 ونفق Tunnel خاص وخدمة VPC داخل حسابك في Cloudflare، مع عنوان workers.dev خاص بك |
| الإدارة | إعادة استخدام تثبيت موجود، وتحديث برنامج الإدارة والرموز والنماذج، وإلغاء تفويض جهاز، أو حذف نشر تم التحقق من ملكيته |

## البدء

1. نزّل ملف APK من [الموقع](https://studio.entropy1221.cc.cd)، وثبّته على Android 8.0 أو أحدث.
2. سجّل الدخول إلى Cloudflare وامنح الإذن لحسابك الخاص.
3. أدخل رمز API الخاص بك في Kaggle. أكمل التحقق من رقم الهاتف على Kaggle إذا طُلب منك ذلك.
4. اختر النماذج، واتصل بتثبيت موجود أو أنشئ نشرًا خاصًا بك.
5. بعد اكتمال النشر، افتح Studio، وابدأ جلسة من Compute، وانتظر حتى يصبح النموذج جاهزًا.

لا يتطلب ملف APK الرسمي من كل مستخدم تسجيل عميل OAuth مستقل أو امتلاك اسم نطاق. تبقى الموارد السحابية في حسابات المستخدم، ويُحفظ سجل المحادثة وملفات الوسائط على الجهاز.

## بنية المستودع

| المجلد | المحتويات |
|---|---|
| `android/` | حاوية Android الأصلية، والتخزين المشفّر، وجسر الشبكة، وواجهة React |
| `manager/` | برنامج الإدارة في Cloudflare، ومخططات قاعدة البيانات، وبيئة تشغيل Kaggle |
| `shared/` | إعدادات النماذج والسياق والتحقق من هوية Notebook |
| `publisher/` | موارد الموقع وقالب الصفحة |
| `scripts/` و`tests/` | أدوات البناء والفحوص المحلية |

راجع [البنية](docs/architecture.md)، و[التطوير](docs/development.md)، و[النشر](docs/publishing.md). الأدلة التقنية التفصيلية متاحة حاليًا باللغة الصينية. ترجمات README لا تضيف لغات إلى واجهة التطبيق.

## بيانات الاعتماد والموارد

- يستخدم إعداد Cloudflare بروتوكول PKCE. يُحفظ رمز Kaggle بوصفه Secret في Worker الخاص بك؛ وتستخدم الطلبات اليومية مفاتيح الجهاز.
- إلغاء تفويض جهاز واحد لا يزيل الأجهزة الأخرى ولا يغيّر مفاتيح الخدمة الأصلية.
- يحدّث خيار **Repair manager program only** برنامج Worker الموجود، مع الحفاظ على Notebook والإعدادات وسجلات الجلسات والأسرار.
- يتطلب حذف النشر التحقق من الملكية ومن الاسم الدقيق. إلغاء تثبيت التطبيق لا يوقف جلسات GPU ولا يحذف الموارد السحابية.
- لا يحتوي المستودع على مفاتيح التوقيع أو الرموز الشخصية أو قواعد بيانات المستخدمين أو سجلات التشغيل أو أوزان النماذج. معرّف OAuth Client ID الخاص بالناشر هو معرّف عام للتطبيق، وليس سرًا لحساب المستخدم.

## التحقق وحدود النماذج

تتحكم Kaggle في أهلية استخدام GPU والتحقق من الهاتف والحصص والتوافر. تختلف قدرات النماذج واحتياجات الذاكرة. اكتمال النشر لا يضمن نجاح الاستدلال.

تغطي الفحوص المحلية استعادة التفويض، وإعادة استخدام التثبيت، وحالة الإيقاف، وإلغاء تفويض الأجهزة، والمهام الخلفية، وعرض المعادلات، ومسارات الواجهة. وتشمل فحوص الصور والفيديو المعلمات والنتائج الرقمية غير الصالحة. لا تثبت الاختبارات بالمحاكاة جودة الصور أو كفاية الذاكرة أو الأداء على بطاقة T4 حقيقية؛ يجب التحقق من ذلك على العتاد المستخدم.

تظل أوزان النماذج والاعتماديات خاضعة لتراخيصها الخاصة. راجع [إشعارات مكونات الجهات الخارجية](android/web/public/third-party-notices.txt).

مشروع مستقل، غير تابع لـ Cloudflare أو Kaggle أو Google أو ناشري النماذج، ولا يحظى بتأييد رسمي منهم.
